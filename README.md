# Occupancy-detection

TI IWR6843 mmWave occupancy / people tracking (PySide + PyQtGraph OpenGL).

## Run

```bash
python live_32d_track_v6.py --data-port COM6 --cli-port COM5 --cfg my_occupancy.cfg
```

Latest iteration: `live_32d_track_v6.11.py` (also mirrored as `live_32d_track_v6.py`).

## Versions

Python scripts in this repo are historical snapshots of the dual-view tracker (`live_32d_track_v3` through `v6.11`).
